# historico/

Roteiros usados na construção do harness, em outubro de 2026, para instalar e provar as ferramentas na máquina de então. Foram substituídos pelos guias numerados de `modo-facil/` e ficam só como registro.

**Não use estes roteiros numa máquina nova:** eles fazem backup de configuração existente, desligam um plugin que hoje é skill de agente (`ui-ux-pro-max`), instalam o Impeccable com hook e usam um formato antigo do `estado.md`, sem a coluna de hash. O caminho atual é `01-maquina-nova.md` e `02-projeto-novo.md`.
